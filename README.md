# Orbit MD — releases

Downloads for **Orbit MD**, the desktop app that lets anyone edit a website's
words and data — not the design. Works with Astro, Gatsby, Next.js and Nuxt sites
whose content is Markdown in git.

## Download

Get the latest version from the [Releases page](../../releases/latest)
(**Orbit-MD.dmg**, macOS on Apple silicon). Open it and drag **Orbit MD** into
Applications. Orbit tells you when a new version is out.

Windows and Linux are coming soon.
